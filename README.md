# BlueHire
This is a centralized platform for local clients seeking local blue-collar workers for handy jobs.

Developers:
- Shervin Dale Tabernero
- Kyle Plando
- Sherielyn Guadiana
- Raziff Gumapon
- Austine John Lomocso
## Features
General
- Identity Verification
- Credibility Points

Client Side
- Booking Requests
- Workers feed
- Job Postings

Worker Side
- Client feed
- Booking management
- Direct Payments 


## Installation

Clone this repository:

```bash
    git clone https://github.com/ero-s/BlueHire
    cd BlueHire
```
